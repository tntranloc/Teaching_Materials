# Teaching Materials: Computational & Quantitative Biology  
### Scientific Presentations & Practical Tutorials  

**Author:** Nhu Loc Thuy Tran  

---

## Overview
This repository contains teaching materials developed during my PhD (2022–2025).  
The content was curated and prepared for public sharing in 2025.  

These materials are designed to support students in **computational biology**, **quantitative genetics**, and **scientific communication**.

---

## Topics Covered
- Introduction to R  
- Data wrangling & visualization  
- Biostatistics basics  
- First hands-on experience in Bash / HPC environments (GWAS-focused)  
- Creating sampling maps  
- Multivariate analysis using MCMCglmm  

---

## Additional Topics
- Project planning  
- How to design an effective scientific poster  
- Giving and receiving constructive feedback  

---

## Repository Structure
Each topic is organized in its own folder and may include:
- **R Markdown (`.Rmd`) tutorials** with code and explanations  
- **Lecture slides (`.pdf`)**  
- **Rendered outputs** (`.html` / `.pdf`) for easy viewing  

---

## How to Use
For the best experience:

- Download the repository locally  
- Open `.Rmd` files in **RStudio** to run and explore the code  
- Use `.pdf` or `.html` files for a static, ready-to-read version
